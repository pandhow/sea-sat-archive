▎卫星通信

Thaicom 4 退役收官，Koreasat 7 应急接管；Thaicom 9（Astranis）推迟至 2027

来源：Developing Telecoms / HeyThailandNews / The Nation ｜ 日期：2026-06 ~ 2026-08
🔴 高
  • Thaicom 4（原 IPSTAR 1，2005 发射）于 2026-06-30 终止宽带服务，功率衰减至约 60%、燃料不足维持轨位，预计 2026-09 漂出 119.5°E。
  • 国家电信（NT）经 NBTC 授权紧急租赁 Koreasat 7（韩国）过渡，用户侧无缝切换；Thaicom 9（Astranis 研制）因同批次制造问题推迟，最早 2027 年发射。
  • NT 经 nexConnect（Eutelsat OneWeb） LEO 网关（Ubon Ratchathani）持续提供卫星互联网；Thaicom 与 Globalstar 合作，2026 年底前推 iPhone 卫星直连（Pathum Thani 地面站）。
💼 BD 关联：泰国"自建应急卫星基础设施"诉求明确（部长强调 NT 为国家应急层）。明华/Astrolink 可推 合规 VSAT / 备份宽带链路，填补 Thaicom 4 退役至 Thaicom 9 到位（2027+）的空窗；多轨道宽带补缺亦可切入 Thaicom→Gulf Space 转型期。

Thaicom 更名 Gulf Space Technology 进入倒计时，成 Amazon Leo（原 Kuiper）早期伙伴

来源：ThaiEdition / APSCC 2026-2（Nile Suwansiri 专访）｜ 日期：2026-08（EGM 记录日 8/20，9/15 股东会）
🟡 中
  • Thaicom Plc 股东大会已批准更名为 Gulf Space Technology Plc，标志从传统卫星运营商转向集成 SpaceTech 公司（GEO + LEO 多轨道 + 空间地理情报）。
  • CEO Nile Suwansiri 确认与 Amazon Leo（原 Project Kuiper，2025-11 更名）在泰合作，定位"可信本地伙伴/服务集成商"，负责落地权、合规、分销与政府关系。
  • Amazon Leo 2026-04 以约 116 亿美元收购 Globalstar（含 Apple 卫星直连频谱），D2D 能力预计 2028 部署，构成对 Starlink 的差异化竞争。
💼 BD 关联：泰国多轨道格局由"Thaicom/Gulf + Amazon Leo + OneWeb + Globalstar"重构。明华/Astrolink 可借 多轨道终端/网关集成与"非 Starlink 替代方案"定位，对接 Gulf Space 转型期的地面段与分销合作窗口。

Starlink 入泰遭遇 51:49 强制泰方控股，监管真空延续

来源：The Thaiger / Nation Thailand / Matichon / Post Today ｜ 日期：2026-08-20 ~ 08-21（8/17 国家航天政策委员会首次会议）
🟡 中
  • 数字经济与社会部长 Chaichanok Chidchob 重申拒绝 Starlink 100% 外资架构，强制泰方持股 >50%（51:49），依据《1999 年外商经营法》；若愿技术转移 + 泰方伙伴可接受。
  • 议题在 2026-08-17 国家航天政策委员会首次会议讨论，涉及外国卫星"落地权"与《航天活动法》草案，方向仍倾向泰企控股。
  • 越南 Starlink 已于 8/13 商用上线（4 网关站/60 万上限），泰国对比之下监管更严；Starlink 在泰仍无商用服务。
💼 BD 关联：Starlink 泰国"监管真空 + 强制合资"形成 合规替代窗口。明华/Astrolink 可推合规 VSAT / 多轨道宽带，并以"技术转移 + 本地伙伴"模式贴合泰方监管偏好，规避与 Starlink 正面价格战。

▎遥感

🔴 重磅：银河航天灵知09泰国立方星（GISTDA CubeSat 1）2026-08-25 成功入轨——中国商业航天首次整星出口东南亚

来源：中新社 / 中国证券报 / 科创板日报 / 北京青年报 / Starpath Global ｜ 日期：2026-08-25（北京时间 11:21 发射）
🔴 高
  • 长征六号丙遥一火箭在太原卫星发射中心发射，将中科卫星14星、中科卫星15星、银河航天灵知09泰国立方星（GISTDA CubeSat 1）等 7 颗卫星送入预定轨道（长征系列第 665 次发射）。
  • 该星由银河航天（北京）抓总研制，用户方为泰国 GISTDA，主要用于为泰方提供国土、农业、生态等地表遥感数据收集，并支撑泰国高校卫星设计/测控/遥感教学。
  • 银河航天为 GISTDA 提供"整星 + 地面系统 + 能力培养"一体化方案，多次组织泰方来华培训、派队赴泰建地面系统——中国商业航天首次实现"卫星-地面-人才"全链条输出，也是首次面向东南亚整星研制、发射及在轨交付。
  • GISTDA 空间技术副执行主任 Phee Choosri 称其为"泰中航天国际合作重要实践"，是人才能力建设与知识交流的载体。
💼 BD 关联（重点）：这是明华/Astrolink 切入泰国航天的标杆性窗口。银河航天验证了"整星出口 + 地面系统 + 培训"交钥匙模式可复制——① 明华遥感方案（农业/生态/灾害 14 章体系）可对接 GISTDA 下游数据应用层；② 借鉴该模式，明华/Astrolink 可面向 GISTDA 后续星座（18 星族 / THEOS-3B·C·D）及东盟其他国家（越南/柬埔寨）推"整星+地面+能力培养"方案；③ 警惕竞争对手（如 Synspective/ICEYE SAR）抢占 GISTDA 数据合作。建议一线 BD 向 GISTDA / 银河航天取官方确认后跟进。

THEOS-3 研发过半（国产率 >20%），2027 发射；GISTDA 规划 18 星对地观测星座

▎发射与卫星

泰国立方星经中国商业航天成功在轨交付——泰国卫星首次"出海发射+整星出口"落地

来源：中新社 / 中国证券报 / 科创板日报 / Starpath Global ｜ 日期：2026-08-25
🔴 高
  • 见"遥感"节重磅条目：GISTDA CubeSat 1（银河航天灵知09）由长征六号丙成功发射入轨，是泰国卫星首次通过中国商业航天实现"研制—发射—在轨交付"全链条落地。
  • 性质界定：非泰国本土自主发射（泰国无轨道发射能力），属"整星出口 / 在轨交付"结果；银河航天同步交付地面系统与培训，构成可持续合作底座。
  • 标志中泰航天合作从"应用采购"升级为"系统共建 + 能力转移"，为后续星座（THEOS 系列、18 星族）与中国火箭/整星出口打开通道。
💼 BD 关联（重点）：明华/Astrolink 可将"中国火箭出口 + 整星交付 + 地面测控 + 能力培养"作为标准化出海产品包，复制银河航天 GISTDA 首单至东盟其他国家；同时卡位 GISTDA 后续发射与在轨服务（运营、测控、数据）环节。

泰国赤道航天港 PPP 可行性推进——GISTDA 任战略支点，中国火箭出口窗口开启

来源：The Nation / Thailand In-Depth / GISTDA ｜ 日期：2026-07（副总理 Yotsanan 参议院汇报），10/15 iConsiam 研讨会（KPMG）
🟡 中
  • 政府制定商业航天发射场（Spaceport）行动计划，采用 PPP 模式，完全私营资本、政府不担全财政；毗邻赤道可降火箭燃料成本约 20%、增载、缩短重访。
  • 定位"和平用途商业航天港"，严格筛查杜绝军事载荷；GISTDA 任三大支点：基础设施连接器、航天法加速器、全球门户（含 Artemis 框架）。
  • 计划三阶段太空经济蓝图，与 KPMG 合作做可行性研究，10/15 在 iConsiam 办研讨会；区域竞争者含澳大利亚、印尼（比阿克）、马来西亚。
💼 BD 关联：航天港 PPP 是中国火箭出口 + 地面测控的关键窗口。明华/Astrolink 可对接中国火箭研制方（长征系列/商业航天）与泰方（GISTDA/高教科研部），提供"发射服务 + 测控网 + 运营"组合；须尊重泰方"和平用途 + 本土伙伴"合规前提。
