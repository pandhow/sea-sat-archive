🛰️ 卫星通信中热度
泰国内阁通过泰日太空合作备忘录，共建低轨卫星星座
来源：曼谷邮报 / Bangkok Post ｜ 日期：2026-06-24
泰国内阁审议并通过与日本双边太空合作谅解备忘录，聚焦低地球轨道(LEO)卫星星座联合科研，由 GISTDA 与 JAXA 牵头，覆盖低轨组网、灾害遥感、全域通信、国土测绘五大板块；日方侧重研发与运维输出，泰方侧重本土落地与产业配套。
▍明华 / SmarCo 业务关联：泰方明确将「全域通信」列为五大合作方向之一，本土卫星研制同步推进。明华可借泰国卫星通信自主化窗口，输出地面站、终端或载荷配套；SmarCo 宜跟进 GISTDA / JAXA 合作生态的供应商准入机会。⚠ 重大合作需以官方与一线 BD 核实。
🧭 导航高热度

▍明华 / SmarCo 业务关联：北斗在泰应用获国家级顶层协议支撑，直接对应明华「北斗商业应用」布局(文昌会议明确对接刘乐推进北斗商业应用)。SmarCo 应把握 7/20 签署窗口期，提前对接泰方 MHESI / GISTDA，争取成为北斗高精度位置服务(物流 / 交通 / 形变监测)落地合作方。⚠ 重大合作需以官方与一线 BD 核实。

与明华 / SmarCo 东南亚 BD 的业务衔接建议
Actionable Recommendations — 按领域给出下周可执行的 BD 动作

① 导航 / 北斗：抓两大窗口，落地高精度位置服务

  1. 泰国 7/20 北斗 MOU 签署窗口：SmarCo 一线 BD 须在 7/20 前对接 MHESI / GISTDA，争取成为北斗高精度位置服务(物流、交通、形变监测、铁路监测)落地合作方，呼应明华「北斗商业应用」布局。
  2. 柬埔寨 CORS 建设势能：借 94 座 CORS 铺开与北斗出租调度先例，向 MLMUPC / JICA 生态推介北斗地基增强与位置服务，争取运维与增值应用订单。
  3. 支点利用：依托中国—东盟北斗基地(南宁)与桂电合作势能，降低 BD 门槛，复制老挝 / 马来西亚示范模式。

② 遥感：走「需求端 + SAR 差异化 + 数据增值」路线

  1. 差异化供给：面对 ST Engineering、航天宏图、NEO-1 等强供给，明华宜聚焦 SAR(云雾穿透)、农业保险、碳监测、洪涝 / 灾害应急等需求端场景，避免与光学产能正面竞争。
  2. 竞合评估：针对航天宏图马来西亚合资，评估 SAR 数据增值、地面站共享或区域代理的互补合作可能。
  3. 早期培育：柬埔寨、泰国农业 / EUDR 合规场景是低成本切入点，可先以数据服务建立关系。

③ 卫星通信：借主权化浪潮输出地面段与终端

  1. 地面段机会：印尼国家通信星 / PSN 低轨星座、泰日 LEO 通信、新加坡 NEBULA 激光链路均释放信关站、地面站、激光通信地面站、终端与运维需求。
  2. 渠道切入：SmarCo 跟进 NSAS、BRIN、GISTDA、Uzma / Boustead 等供应商生态，争取地面系统配套与联合投标。

④ 区域协同与风险

以中国—东盟卫星遥感应用中心(ACSAC)、中国—东盟北斗基地为官方支点，借合作势能降低 BD 门槛；重大合作(含泰国北斗 MOU、PSN 星座、ST Engineering、航天宏图合资)务必以官方公告与一线 BD 核实后再推进商务动作。
