▎卫星通信

Starlink 越南商用延续，4 网关站落地、海上/偏远成主战场

来源：Entrepreneur APAC / Vietnam.vn / VietnamNet / SpaceSGP 分析（8/13 上线，8 月持续）｜ 日期：2026-08-13 起

🔴 高

  • SpaceX 全资子公司 Starlink Services Vietnam 于 8/13 正式开放商业接单，住宅约 $43/月起、企业起价约 $57，硬件约 $329–440；已建 4 个境内网关站（富寿 / 岘港 / 胡志明等）。

  • 试点上限 60 万终端、期限至 2031-01-01，四部门（科技 / 国防 / 公安）联合监管，数据须经越南境内网关；越南系其第 6 个东南亚市场。
  • 越捷航空（Vietjet）已签机上网络连接协议；多家分析指出主战场在海上、偏远、备份通信——价格约为 VNPT 光纤 5 倍以上，对城市光纤不构成直接竞争，渔船/邮轮成关键客群。
💼 BD 关联（Astrolink / 明华）：Starlink 入越后"地面补盲 + 合规网关周边"成明确切口——推海上/偏远 VSAT 备份、渔政/海警互联、跨境企业专网备份方案，与 Starlink 错位互补；关注其网关站周边合规集成与运维窗口。

VINASAT-3/4 国家通信卫星换代加速，Thales 推进与 VNPT 合作

来源：Vietnam.vn（科技部 4/2 与 Thales 会谈）/ Mondaq（Duane Morris）｜ 日期：2026-04 ~ 2026-08（持续进行）

🔴 高

  • 越南科技部确认推进 VINASAT-3 项目，并规划 VINASAT-4 作为 VINASAT-2（设计寿命约 2030 到期）的替代星，定位"数字主权 + 基础设施韧性"。
  • 法国 Thales 于 4/2 在河内与科技部会谈，表示已与国有 VNPT 讨论、准备提供通信卫星（Ku/Ka 多频、星上数字处理器）方案，并提及曾参与印尼 SATRIA-1。
  • VNPT 被指派为项目实施主体；VINASAT-1（2008 发射）可靠性下降，换代紧迫性上升。
💼 BD 关联（Astrolink / 明华）：国家级通信星换代是中长期大单窗口——可切入地面段、频段协调、测控与增值通信服务咨询；以"中国航天 GEO 通信星 + 地面应用"差异化方案参与关系卡位，不与 Thales 正面争夺主星制造。

▎导航（GNSS / 北斗）

北斗农机/导航规模化 + 进口农机 10/1 合规窗口（含条款核实提示）

来源：AMI 东南亚北斗农机报告 2026 / 越南工贸部 MOIT Circular 12/2026/TT-BCT / The Indus Wire · ZS Iron · Analytic Sector（10/1 生效）｜ 日期：2026-04~2026-08

🔴 高

  • 北斗在越南农业加速落地：AMI 2026 报告显示越南北斗兼容农机出货量位列东南亚第二梯队（仅次于印尼、与泰国并列），湄公河三角洲北斗短报文农机远程监控调度试点已实现作业效率 +18.5%、燃油 −9.2%；越南本土已有 3 家企业获北斗农机技术授权布局本地化生产。
  • 进口农机合规窗口：越南《第 12/2026 号通知》(Circular 12/2026/TT-BCT) 多源确认于 2026-10-01 生效，覆盖进口农机（拖拉机 / 插秧机 / 收割机 / 灌溉设备等）的入市合规；VAST 自 8/1 起要求进口农机强制型式认证 + CR 标志，未合规不予清关。
  • 北斗 PPP 完成在轨升级（7/31 CSNO 公布），PPP 水平 <0.3m、双星座 59 颗修正卫星，亚太直接受益；交通部层面出现集成北斗车辆追踪意向。

⚠️ 事实核查（归零纪律 · 结论反向校验）：本期对"前期报道的 Circular 12/2026 强制预装北斗三号双模 + VINA-STAR 认证"做反向核验——本轮公开检索（The Indus Wire / ZS Iron / Analytic Sector / Global Sector Hub 等多源）将 Circular 12/2026/TT-BCT 主要描述为"进口农机越南语安全标签 / 能效标签 / CR 型式认证 / AI 设备备案"等合规要求，关于"北斗双模强制预装"的细节未能在越南官方或英文权威信源中得到独立二次确认。建议一线 BD 以越南工贸部正式条文为准；明华可将"北斗模块 + 认证代理"作为合规配套机会推进，但勿将"强制北斗"对外承诺为已落地政策。

💼 BD 关联（Astrolink / 明华）· P0：10/1 进口农机合规窗口 + 北斗在越规模化是本期最高优先级切入点；明华可牵头北斗模块供应 + 本地认证代理 + 预校准一站式服务，绑定华南/山东出口链，但须先以 MOIT 正式条文核实具体强制范围再对外承诺。

VNGEONET 65 基准站 + 农业 RTK 本地化技术基础

来源：越南农业与环境部 / VCCA 2026 最佳论文（越南农业大学 RTK 基站）｜ 日期：2026-03~2026-07

🟡 中

  • 越南现有 VNGEONET 65 个 CORS 基准站，主要服务测绘与土地管理；当流动站距基准站 >30km 时定位误差上升，尚不擅长多机同时作业的农田场景。
  • VCCA 2026 最佳论文"农业机械 RTK 基站"由越南农业大学团队完成：本地 RTK 站为农机提供实时修正，半径 10km 内平均误差 1.2–2cm、支持多流动站并发，验证了农业北斗/RTK 本地化可行性。
💼 BD 关联（Astrolink / 明华）：本地 RTK/北斗基站方案可对接明华北斗终端，提供"终端 + 基准站 + 农业应用"套件；长期与农业部/测绘地信部门保持技术交流，储备政府侧触点。

北斗 PPP 升级红利 + 车辆追踪集成意向

来源：中国卫星导航系统管理办公室 CSNO（7/31）/ 越南交通部动向｜ 日期：2026-07~2026-08

🟡 中

  • 北斗完成全面在轨升级（7/31 公布），PPP 水平精度 <0.3m、双星座 59 颗修正卫星，亚太地区直接受益。
  • 越南交通部层面出现将北斗集成进车辆追踪 / 物流监管的意向，与农机北斗应用形成"陆上 + 田间"双线推进。
💼 BD 关联（Astrolink / 明华）：借北斗 PPP 升级红利，推车辆追踪 / 物流 / 车队管理北斗终端，作为农机 P0 项目的自然延伸，形成"北斗应用套件"。

▎遥感

VNSC 和乐航天中心运营，LOTUSat-1 SAR 目标 2027 底发射

来源：越南政府网 chinhphu.vn / Tuoi Tre / VOV（3/13 启用，2027 待发）｜ 日期：2026-03-13 启用，2027 待发

🔴 高

  • 越南国家航天中心（VNSC，Hoa Lac 高科技园，日 ODA 贷款逾 7 万亿越盾 / 约 2.66 亿美元）已于 3/13 盛大启用，含运控中心、卫星数据应用中心、9.3m 天线地面系统、洁净间。
  • LOTUSat-1（首颗 SAR 雷达星，约 600kg，日越联合制造）已完成制造、地面系统已安装、运维人员已培训；因日本 Epsilon-S 试车故障推迟，官方口径目标 2027 年底 发射，具 1m 分辨率、昼夜全天候能力。

⚠️ 事实核查：LOTUSat-1 目前 仅完成制造、尚未发射，官方与多源一致口径为"目标 2027 年底"。部分中文科技媒体曾误报"已成功发射"，本期拒绝该误报，延续第 027/034 期已报结论，严禁写成已入轨。

💼 BD 关联（Astrolink / 明华）：日越绑定项目，宜寻 NEC/住友等日本主承包商二级合作，切入地面站周边设备与遥感应用；以自研遥感方案对接 VNSC 数据应用中心，提供农业/海洋/应急 downstream 能力。

VNSC×JAXA ALOS-2/ALOS-4 数据共享修订，入轨前已获更高分辨率数据

来源：Vietnam.vn / 越通社（5/2 修订协议）｜ 日期：2026-05-02

🟡 中

  • 5/2 越日签署 ALOS-2 / ALOS-4 卫星数据共享修订协议：JAXA 继续提供 ALOS-2 与新一代 ALOS-4（PALSAR-3，幅宽更宽、分辨率更高）先进数据，VNSC 负责接收、利用并提交应用报告。
  • 该协议在 LOTUSat-1 入轨前即打开 ALOS-4 更高分辨率数据法律通道，越南可先行用于灾害响应、湄公河三角洲水稻监测、洪水快速监测与气候变化研究。
💼 BD 关联（Astrolink / 明华）：越南遥感数据生态正加速成型，明华可借 ALOS 数据应用经验，对接 VNSC 数据应用中心提供农业/灾害 downstream 方案，强化日越项目二级合作黏性。

越南小卫星自主能力路径成型，LOTUSat-2 规划本土制造

来源：Zone.ci 战略分析 / 越南政府网 / VNSC｜ 日期：2026-08（持续）

🟡 中

  • 十年路径：PicoDragon(2013,1kg) → MicroDragon(2019,50kg,日越合造) → NanoDragon(2021,3.8kg,纯越自制,载 AIS 海上船舶追踪) → LOTUSat-1(600kg,日造越参与)。
  • LOTUSat-2 按国家空间战略规划，将由越南本土工程师在外国专家监督下自主制造，目标 2030 前具备独立设计制造高分辨率 EO 卫星能力。
  • 能力建设重心已从"拥有卫星"转向"掌握数据利用链"——地面站工程 + 研发设备（约 250 万美元）招标反映数据分析补强取向。
💼 BD 关联（Astrolink / 明华）：越南自主遥感能力成长是中长期合作底座；明华可在地面站周边设备、数据应用平台与人才培训（借海南卫星数据与应用研究中心能力）提前卡位。

▎发射与卫星

VinSpace（Vingroup）× SpaceX 签正式发射合同，2027 Q2 发越南首颗私营星座

来源：越通社中文 / SatNews / SmallSatNews（8 月中旬签约）｜ 日期：2026-08（2027 Q2 发射）

🔴 高

  • VinSpace（Vingroup 航天子公司）于 8 月中旬与 SpaceX 签正式发射服务合同，2027 Q2 搭 Transporter 拼车任务发射首批商业纳米卫星（"Make in Vietnam"）。
  • 载荷含高分辨率光学遥感 + 窄带物联网/IoT 通信，用于农业监测、海岸带管理、基础设施与海事 M2M；采用太阳同步轨道（SSO）。
  • 标志越南从国家院所项目转向私营商业航天，VinSpace 目标成为全栈（设计—AIT—发射管理—运营—下游数据）航天公司；Vietjet 同期签 Starlink 机上网络，Vingroup 航空+航天双线布局。
💼 BD 关联（Astrolink / 明华）：越南首个私营星座具"早卡位"价值——可在 AIT、地面测控站、下游数据分发（农业/海事/应急）切入合作；明华遥感方案与 VinSpace 光学载荷形成应用层互补，建议尽快建立技术对接。

越南无自主发射能力，入轨全靠外部运载

来源：综合本期各源｜ 日期：2026-08-31 评估

⚪ 低

  • LOTUSat-1 将借日本运载 2027 发射；VinSpace 借 SpaceX Transporter；越南本国无发射场 / 运载火箭。
  • 本期无新增自主发射或发射场建设公开动态，如实标注低热度，未编造。
💼 BD 关联（Astrolink / 明华）：越南"无发射能力"恰是明华/中国火箭出口与发射服务的潜在入口——可关注未来越南政府对发射服务的采购意向，但当前以数据与应用层合作为更务实切入点。

🧭 与明华 / Astrolink BD 的业务衔接建议

  • P0北斗农机合规窗口 + 北斗模块/认证服务（10/1 倒计时）：明华牵头北斗模块供应 + 本地认证代理 + 预校准一站式服务，绑定华南/山东出口链；须先以 MOIT 正式条文核实 Circular 12/2026 具体强制范围再对外承诺（前期"北斗双模强制"细节本轮未二次确认）。
  • P0VinSpace×SpaceX 2027 早卡位：对接越南首个私营星座的 AIT、地面测控与下游数据分发（农业/海事/应急），以明华遥感方案形成应用层互补。
  • P1Starlink 商用互补：海上/偏远/备份 VSAT、渔政海警互联、企业专网备份，与 Starlink 错位竞争；关注网关站周边合规集成。
  • P1VINASAT-3/4 国家换代：以中国 GEO 通信星 + 地面应用差异化切入 Thales×VNPT 主星之外的地面段/频段咨询窗口。
  • P1LOTUSat-1 SAR + VNSC×JAXA ALOS-4：日越绑定项目寻 NEC/住友二级合作，配套遥感应用对接 VNSC 数据应用中心。
  • P2北斗 PPP 车辆追踪终端：借 PPP <0.3m 红利推物流车队北斗终端，延伸农机套件。
  • P2《越南航天法》立法关系卡位：借第 57/193 号决议与 VAST/VNSC 建长期技术—数据合作通道，储备自主遥感能力成长红利。
