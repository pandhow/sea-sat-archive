▎卫星通信

🔴 高Starlink 越南试点框架落定：4 网关 / 60 万上限 / 5 年试点至 2031
来源：VietNamNet（6/29） · vietnam.vn · 人民报（Nhandan） · Geopolitical Monitor｜日期：2026-06~09
  • 越南无线电频率局 2026/2/13 向 Starlink Services Vietnam Co., Ltd.（SpaceX 在越全资子公司）颁发频率与设备使用许可；科技部另发电信服务牌照，双重牌照框架确立。
  • 初期部署 4 座境内网关站：富寿省（Phú Thọ）、岘港市（Đà Nẵng）、胡志明市双站（2 处）。数据境内落地、流量不经星间链路外传，契合越南《网络安全法》与 53 号议定数据本地化要求。
  • 试点用户上限 60 万终端（约占越南固网宽带 2.5%），试点期最长 5 年至 2031/1/1；官方定位为"对地面网络的补充而非替代"。
  • SpaceX 越南子公司注册资本约 116 万美元，为越南电信业首个 100% 外资实体。
明华 / Astrolink 不宜以"替代运营商"叙事切入。建议定位 "地面段补位 + 应急通信备份 + 海洋 / 偏远场景"：越南官方已明言 Starlink 价值在风暴 / 洪水等灾害备用与离岛、山地补盲——这正是我方"灾害遥感 + 卫星通信保障"打包方案的入口，且不与 Viettel / VNPT 正面冲突。
🟡 中商业运营启动时间口径不一：不把"已规模商用"作已证实结论
来源：060 期（越南语源） · VietNamNet（6/29 英文主流源）｜日期：2026-08~09
  • 060 期（9/21）据越南语源报道：2026/8 起商用、9 月首批 254 套 Standard 4X 移交 13 省市（含山罗省 36 台、6 个月免费），273 村 + 44 弱信号点须 10/30 前覆盖。
  • 但英文主流源（VietNamNet 6/29 引 Starlink Services Vietnam 总经理 Do Ba Thich）仍称"正准备基础设施、未公布上线日期、预期 2026 年 7 月可用"——时间线存在口径差。
  • 本期按归零规范：不将"已规模商用"作为已证实结论，建议以越南电信局（VNTA）/ Starlink Services Vietnam 官方月度公告复核覆盖进度。
可用"上周预警对了"式能力背书敲门：若 10/30 覆盖节点在即、偏远省份急需灾害 / 海洋通信，我方"遥感 + 通信保障"包可作政府侧补充方案；先核实真实覆盖进度再报价，避免踩空。
⚪ 低本土运营商立场：固网与 5G 主导，Starlink 定位补充
来源：VietNamNet · vietnam.vn｜日期：2026-06~09
  • 越南地面电信基础设施完善，Viettel / VNPT / MobiFone 在人口密集区优势稳固；官方与专家均判断 LEO 卫星"难以成为大众宽带、不宜与现有网络直接竞争"。
  • Starlink 价值锚定利基：偏远山区 / 离岛、灾害备份、海上油气与航运、矿业林业等孤立作业点。
对明华 / Astrolink 而言，越南不是"卖带宽"市场，而是"卖体系 + 运维 + 应急场景"市场；对接政府应急、海洋经济与能源孤立作业点，比争夺消费端更可行。

来源：越南工贸部（MOIT）Circular 12/2026/TT-BCT（4/18 签发） · zsiron / atfxoops（多版本，待核） · 060 期｜日期：生效 2026-10-01（待官方确认）
  • 规定进口拖拉机、水稻插秧机、谷物烘干机等须预装北斗三号（BDS-3）双模 GNSS 模块并取得 VINA-STAR 认证，未合规单位禁止清关；认证处理周期约 6–8 周。
  • ⚠️ 网络二手源存在 7/1、10/1、6/1、5/1 多个冲突生效日版本，本期沿用 060 期 10/1 口径，生效日以 MOIT 官方公报为准。

P0 级切入点：这是明华 / Astrolink 北斗出海最明确的合规抓手。可对接中国农机出口商（粤 / 桂 / 鲁占比 >70%）提供北斗三号双模模块 + VINA-STAR 认证辅导，以香港平台作"中立合规节点"规避主权敏感；窗口仅剩 3 天，建议立即摸排粤桂鲁头部出口商意向。

▎遥感

🔴 高VNSC 和乐中心启用 + 三大优先级（LOTUSat-1 / VNREDSat 连续性 / 地面段 AIT）
来源：Vietnam News（opinion，VAST 采访） · 越南国家航天中心｜日期：2026-03-13 启用
  • 越南国家航天中心（VNSC，和乐高科园）2026/3/13 启用，标志越南空间能力从"运营进口系统"转向"自主设计 / AIT / 数据 exploitation"。
  • 三大优先：① EO 系列连续性——VNREDSat-1（光学，2013/5/7 发射）超期 14 年仍运行，2020 起提供近 3 万景影像；② LOTUSat-1 雷达星带入运行 + 下一阶段；③ 地面站 / 运控 / 数据 + 和乐 AIT 设施校准。
  • 痛点：数据碎片、缺乏标准化与互操作、时序不连续、缺地面真值——恰恰是外部"数据增值 + 分析产品化"可补的缺口。
P0：LOTUSat-1（SAR）入役前越南雷达能力缺口 = 我方 SAR 数据补位 + 洪涝 / crop 分类分析产品化窗口；和乐 AIT 设施建设 = 地面段 / 产线合作机会。建议以"区域连续性遥感产品线（洪水 / 烟霾 / 作物）"对接 VNSC。
🟡 中VNREDSat-2 与法国 CO3D 绑定进入新阶段（苏林巴黎峰会推进）
来源：The Europe Today（9/14） · vietnam.vn · 法国驻越大使馆展览｜日期：2025-05 DoI / 2026-09 推进
  • 基础：2025/5 河内（马克龙访越）VAST × Airbus Defence and Space × CNES 签《合作意向声明》（DoI），探索新一代 EO 系统并引入法国 CO3D 三维光学星座技术。
  • 2026/9 巴黎空间峰会（苏林 9/7–12 出席）推进 VNREDSat-2，目标 co-development、提升越南在任务定义 / 系统设计 / 子系统 / 地面系统的参与度。
  • 法方已占"co-design"入口；越南路线明确"从买整星 → 共研 → 自主能力"。
P1："越南整星没门、地面段 + 数据管线 + 算法才有门"（060 沉淀）。法线已占 co-design 上游，我方宜避开正面竞争，做下游数据增值 + 培训 + 分析产品，以"中立第三方 + 可审计时间戳"差异化切入。
🟡 中本土商业航天梯队成型（VTX / VinSpace / CT Verse / Vegastar / OSB）
来源：Vietnam News｜日期：2026-09
  • 越南已形成覆盖卫星通信、系统集成、数据服务、研制设计、地面站、UAV、设备软件数据产品的本土企业梯队：VTX、VinSpace、CT Verse、Vegastar、OSB 等。
  • 空间市场早期，企业参与从"系统运营"向"研制 + 地面 + 数据产品"延伸，但人才保留与"培训—实战—补偿"机制仍是瓶颈。
P2：可作系统集成与数据服务的本地合作方筛选池；VinSpace（与 SpaceX 合作纳米星）兼具渠道与本地合规属性，值得单列跟踪。
