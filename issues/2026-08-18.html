▎卫星通信

千帆星座(G60/上海垣信卫星)拟落地柬埔寨卫星互联网——首相级会晤，监管框架制定中

来源：柬中时报(cc-times.com) 2026-07-17；搜狐 2026-07-17；华人头条 2026-07-17；cambolist 2026-07-17

🔴 热度：高

  • 7月17日，柬埔寨首相洪玛耐(Hun Manet)借出席上海 WAIC 世界人工智能大会之机，会见上海垣信卫星科技董事长郑杰，探讨"千帆星座"(又称 G60 星链)低轨宽带卫星互联网落地柬埔寨。
  • 千帆星座在轨卫星已达 238 颗、年内目标扩容至 324 颗；已获巴西运营牌照，并与马来西亚、泰国、哈萨克斯坦等多国达成通信合作意向，东盟落地版图持续拓宽。
  • 洪玛耐透露：柬埔寨邮电部(MPTC)正在制定卫星互联网与卫星通信服务监管框架，法规出台后将优先推动偏远/农村地区覆盖，并防范服务被非法滥用。
  • 会晤亦提及卫星直连手机(Direct-to-Cell, D2C)技术——垣信在该方向处于研发前沿，为后续地面补盲提供想象空间。
💼 BD 关联（明华 / Astrolink）：中资卫星互联网出海的"国家队级"窗口。明华/Astrolink 可定位为垣信在柬落地的二级合作伙伴——对接 MPTC 监管框架合规落地、提供终端/VSAT/网关周边与偏远农村覆盖方案，并以 Astrolink 的东南亚渠道做终端分销与运维。属 P0 级优先切入。

Starlink 柬埔寨"年内待上线"，监管严格、已现非法设备查处案例

来源：Data Center Dynamics 2026-08；cambolist 2026-05-25；东方财富股吧 2026-07-05

🟡 热度：中

  • Starlink 已覆盖东南亚 6 国（菲、印尼、马来、新加坡、东帝汶，越南于 2026-08-12 正式商用）；覆盖地图将柬埔寨与老挝列为"今年内推出"市场，但截至本期尚未在柬正式上线。
  • 柬埔寨对卫星互联网监管严格：2026-05-25 国公省打击电诈行动中，警方查封别墅并查获非法使用的 Starlink 接收设备，官方明确"未经授权使用属违法"。
  • 监管框架落地前，星链在柬的商业服务仍受政策约束，节奏取决于 MPTC 法规出台进度。
💼 BD 关联（明华 / Astrolink）：Starlink 落地后与明华形成"互补而非竞争"——可切入合规网关周边、海上/偏远 VSAT 备份、企业专网；在监管真空期做合规咨询服务，规避电诈类滥用风险连带。属 P1。

邮电部推进国家无线电频谱规划草案，对齐 ITU Region 3

来源：dgCambodia 2026-06-20（引 MPTC 官方公告）

🟡 热度：中

  • 6月19日，邮电部秘书 Kong Phalla 牵头讨论国家无线电频率频谱规划实施草案，将柬埔寨频率分配对齐 ITU 第3区(Region 3)频段规划。
  • 草案按无线电业务类型分配频谱资源，强调高效利用与频率使用权法律确定性，为包括卫星通信在内的频谱分配奠定法律基础。
  • 运营商与设备供应商需关注最终分配方案对网络规划与许可要求的影响。
💼 BD 关联（明华 / Astrolink）：卫星互联网牌照与频谱分配是"监管前置"入口。明华可提前卡位、跟踪 MPTC 法规与频谱分配，为后续代理中资星座落地做合规铺垫。属 P2（监管前置）。

▎导航（GNSS / 北斗）

柬中环境技术合作 MoU 引入北斗，用于森林与生态监测

来源：华人头条(52hrtt) 2026-03-12；东盟头条(aseantop) 2026-03-13；搜狐 2026-03-13

🟡 热度：中

  • 3月12日，柬埔寨环境部与中国广西国土资源规划设计集团(广西国企)在南宁签署《柬埔寨环境现代化建设技术合作谅解备忘录》。
  • 合作重点推进北斗卫星导航系统(BDS)及卫星遥感在森林资源监测、生态保护、环境监管中的应用，并建设环境数据平台。
  • 该 MoU 是柬埔寨环境领域现代化的重要技术入口，北斗以"环境管理"场景率先落地。
💼 BD 关联（明华 / Astrolink）：北斗在柬以环境部 MoU 为桥头堡。明华可借中柬合作延伸，推动北斗模块/精准农业、车载追踪在柬落地，与农业估产、灾害监测场景绑定。属 P1。

北斗全球服务覆盖东盟十国，柬埔寨规模化应用待落地

来源：今日头条 2026-06（北斗全球化进展综述）

⚪ 热度：低

  • 截至2026年6月，北斗已向全球 140+ 国家提供常态化服务，东盟十国(含柬埔寨)全线接入。
  • 柬埔寨目前以环境部 MoU 为具体应用入口，规模化行业落地(交通、农业、测绘)尚处早期。
💼 BD 关联（明华 / Astrolink）：长期关系卡位——在东盟北斗渗透大势下，优先锁定柬政府/行业首批应用示范，建立先发渠道。属 P2。

▎遥感

广西国土规划集团 × 柬埔寨国土规划与建设部 签署卫星遥感/GIS 合作 MoU

来源：中国城市规划网/今日头条 2026-08-05（报道 7/28 签约）；taibo.cn 英文 2026-07-28

🔴 热度：高

  • 7月28日，广西国土规划集团与柬埔寨王国国土规划和建设部(副总理兼部长赛欧松出席)签署卫星技术合作谅解备忘录，规格升至副总理级。
  • 合作立足卫星遥感与地理信息系统(GIS)，覆盖测绘、地籍管理、土地管理、城市规划、地理信息平台建设及科研创新。
  • 双方将成立联合工作组推动项目落地，目标打造"中柬地理信息与城市管理务实合作样板"——是 3月环境部 MoU 在国土规划维度的延伸升级。
💼 BD 关联（明华 / Astrolink）：中柬地理信息合作样板=明华遥感能力的天然出口。可借该 MoU 提供对地观测数据/应用(农业估产、土地确权、城市规划)，依托既有长光/四维等渠道做数据与服务供给。属 P0。

环境部"Green 2.0"战略：用卫星影像 + 无人机取证森林犯罪

来源：The Star (马来西亚) 2026-08-11（报道 8/10 WWF-Cambodia 研讨会）

🔴 热度：高

  • 8月10日，环境部长 Eang Sophalleth 在 WWF-Cambodia 研讨会上提出"Green 2.0"扩围战略，强调以现代卫星影像与无人机强化环境执法取证。
  • 卫星影像可提供森林覆盖与土地利用的历史变化证据，用来反驳"已占用多年"类土地侵占主张；无人机补地面难以到达区域的实时画面。
  • 该机制隶属《Environmental Chakra Strategy 2023–2028》(Clean / Green / Sustainable 三大支柱)，并扩大律所、NGO、社区等多元主体协作。
💼 BD 关联（明华 / Astrolink）：卫星影像+无人机+AI 森林/土地监测是明华遥感方案的现成场景。可对接环境部提供"变化检测+取证报告"产品，与 ODC 公开平台数据互补形成政企组合。属 P1。

Open Development Cambodia 森林扰动预警平台上线（含 SAR 数据源）

来源：Open Development Cambodia 2026-06-24

🟡 热度：中

  • 6月24日，ODC 在挪威人民援助(NPA)、Global Forest Watch、海因里希·伯尔基金会支持下正式上线森林扰动预警平台。
  • 整合 GFW、SERVIR-SEA 与 JICA-JAXA JJ-FAST(ALOS-2 PALSAR-2 SAR，50m，45天重访，不受云影响) 多源数据，通过 Telegram 向订阅区域推送近实时(12–15天)森林扰动警报。
  • 面向 CSO、社区森林组、原住民、政府、研究者等开放，降低复杂地理空间数据的应用门槛。
💼 BD 关联（明华 / Astrolink）：SAR(云免)数据是柬热带多雨环境的刚需。明华可定位为高质量 SAR/光学数据供给方或平台增值分析服务商，补充 ODC 开源能力。属 P2。

▎发射与卫星

柬埔寨拟 5 年内自主发射卫星，研究设立国家航天管理机构

来源：Asian Speech 2026-04-25；华人头条 2026-04-24；今日头条 2026-04-24（引邮电部长谢万迪/Chea Vandeth 4/23 研讨会讲话）

🟡 热度：中

  • 4月23日，邮电与通讯部大臣谢万迪在"卫星与卫星技术监测/数据采集"研讨会闭幕式上表示，政府正研究未来 5 年内自主发射卫星的可行性。
  • 同步研究设立国家级航天管理机构，统筹卫星与空间技术发展；现阶段仍优先引入国际卫星服务，服务农业、环境监测、土地管理与城市规划。
  • 研讨会吸引约 210 名代表，高光谱成像公司 Pixxel Space Technologies 派员参与，凸显对地观测技术被列为数字基建基础能力。
💼 BD 关联（明华 / Astrolink）：属长期关系卡位——柬自主卫星尚无近期发射节点，但航天管理机构设立与人才计划是早期介入窗口。明华可保持跟踪、待官方路径明确再推进。属 P2。
