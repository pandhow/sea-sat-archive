▎卫星通信

🟡 Lintasarta 强化与 Starlink 企业级合作，BATIC 2026 巴厘大会定调"Beyond Infrastructure"

来源：Swan Pedia / The Business Global Magazine（BATIC 2026 巴厘，2026-08-25）

日期：2026-08-25

🟡 中
  • Lintasarta（Indosat Ooredoo Hutchison 子公司）与 Starlink 自 2024 年合作，本次在 BATIC 2026 巴厘大会深化，聚焦企业级高容量连接。
  • 提出 "Beyond Infrastructure" 四大支柱：Connectivity、Cloud、Cybersecurity、Collaboration-AI（4C），将卫星连接嵌入更宽的数字化基础设施生态。
  • 定位为地面网络在偏远/复杂地形地区的互补层，而非替代；面向企业客户弹性扩展连接。
💼 BD 关联：印尼企业级卫星连接主战场已由零售下沉至"卫星+地面混合 + 行业云网安"一体化。明华/Astrolink 应避开零售正面竞争，聚焦企业 backhaul、行业专网与运维集成、合规转售，并可对标 4C 把卫星通信打包进数字化解决方案。

🟡 中加里曼丹省发放数千台 Starlink 设备，政府级卫星下乡规模落地

来源：jawawa.id（2026-08-06，省长 Rakordes 协调会）

日期：2026-08-06

🟡 中
  • 中加里曼丹省政府向 13 个区县发放 Starlink 设备，优先用于偏远与盲区的中小学（SD/SMP）与社区卫生中心（Puskesmas）。
  • 单批分配：Katingan 287 台、Lamandau 170 台、West Kotawaringin 176 台、Seruyan 131 台等，合计数千台，覆盖教育数字化与基层卫生服务。
  • 体现印尼地方政府以卫星手段补齐数字鸿沟的规模化趋势，而非单点试点。
💼 BD 关联：政府级卫星下乡带来设备运维、培训、网络管理的持续需求。明华可面向地方政府的卫星连接运维与集成服务切入，避开设备零售、主打"交钥匙运维"。

🟡 本土 GEO 容量持续扩张：PSN Nusantara Lima（160+ Gbps）瞄准 2027 商用填充

来源：Space Odyssey Hub（公司档案更新 2026-08-16）

日期：2026-08-16（档案更新）

🟡 中
  • PSN（Pasifik Satelit Nusantara）为印尼首家私营卫星运营商：Nusantara Lima 为 Ka 波段 VHTS，101 点波束、160+ Gbps，覆盖印尼/马来/菲律宾，配 7 座地面站；Nusantara Tiga（SATRIA-1）150 Gbps、11 座地面站；Nusantara Satu 为早期 HTS。
  • 2025 年 PSN 增配史上最大容量块；Nusantara Lima 面向印尼/马来/菲律宾的 2027 年商用填充（commercial fill）。
  • 地面段资产（11+7 座地球站、Cikarang 主控 + Banjarmasin 备份）是 archipelago 连接的核心壁垒。
💼 BD 关联：本土 GEO 容量 + 地面站网络是明华可对接的backhaul/容量合作方；在 3T 地区，明华可与其形成"国际卫星资源 + 本地地面段"互补，而非正面竞争。

▎遥感

🔴 印尼发布 Piksel 国家主权 EO 分析平台（BIG × Geoscience Australia，50TB 开放数据）

来源：Spatial Source（2026-10，BIG 印尼地理空间信息局发布）

日期：2026-10（近期发布）

🔴 高
  • 印尼地理空间信息局（BIG）联合 Geoscience Australia 推出主权地球观测分析平台 Piksel，旨在强化印尼环境与自然资源的测绘、监测与可持续管理能力。
  • 已集成 50 TB 覆盖全印尼的数据（Sentinel-1/2、Landsat 5/7/8/9），通过开放 API 免费提供；含 6 项服务：数据浏览器、交互地图、Piksel Sandbox（JupyterLab + Open Data Cube）、地理空间处理、OGC Web 服务、支持协作。
  • 已实际用于洪水识别、海岸线变化、水稻种植监测、矿区计算、红树林分类、地热电厂周边地表温度等场景；Anak Krakatau 火山 2026-09-05 喷发前活动增强亦由 Piksel 处理 Sentinel-2 时序影像记录。
💼 BD 关联：Piksel 是印尼主权 EO 数据底座，开放生态利好增值服务层。明华可切入 EO 数据应用/增值/灾害产品（对接 BIG/BNPB），并关注与澳方 Geoscience Australia 的合作生态；同时可对标其"开放 API + 应用层"模式，包装明华遥感产品。

🔴 楠榜一号（Lampung-1）高光谱卫星发射，浮出数据主权讨论

来源：BBC 中文 / publiklampung / 中国驻棉兰总领馆经贸之窗（引 ANTARA）（发射 2026-08-05；BBC 深度分析近期）

日期：发射 2026-08-05；数据主权讨论近期发酵

🔴 高 · 多源确认发射成功
  • 发射成功三源确认：楠榜一号于 2026-08-05 在中国山东外海由长征捷龙三号遥十二运载火箭搭载发射，属 OSE Hyperspectral Twin Satellites 任务，由 STAR.VISION Aerospace（地卫二）研制（BBC 中文 / 印尼 publiklampung / 中国驻棉兰总领馆引 ANTARA 一致）。
  • 高光谱 + AI，可监测洪水、山体滑坡、林火、作物健康、河流水质、土地变化、灾害管理与基建；合作始于 2025-05 楠榜省长与地卫二 MoU，由 BRIN 协调推动（山东-楠榜友好省框架）。
  • 数据主权关切：BBC 报道，卫星所有权与控制权属地卫二，楠榜省政府与 BRIN 仅共用民用数据（农业/海洋/公共服务）；因楠榜位于具战略地位的巽他海峡入口，外界关注数据安全机制与"防止他国国防/军事用途"条款。
💼 BD 关联：这是"中印尼省级高光谱卫星合作"样板，高光谱 + AI 遥感正是明华直接赛道。明华可借香港中立平台参与数据治理/应用层，规避数据主权敏感；并关注该"友好省 + 卫星"模式是否向其他省份复制（山东-楠榜为先例）。

🟡 BRIN 红树林退化卫星预警系统：SAR + 光学 + 贝叶斯，探索纳入中国高分/HY 卫星

来源：EnviroNews Asia（印尼-中国卫星遥感应用研讨会，雅加达，2026-10-14）

日期：2026-10-14

🟡 中
  • BRIN 地球信息研究中心开发基于卫星的红树林退化早期预警系统，结合 Sentinel-1 SAR + Sentinel-2 + Landsat，用概率检测与贝叶斯更新算法动态更新变化概率，输出 4 级警报（safe/warning/alert/high alert）。
  • 在中爪哇 Semarang 测试（地面沉降约 13–15 cm/年，红树林在鱼塘间碎片化），并基于 TanDEM-X 树高 + NASA GEDI 校准生物量、结合土壤有机碳库估算蓝色碳汇风险。
  • BRIN 明确探索纳入中国高分（Gaofen）卫星与 HY 卫星系列补充光学/雷达观测，强化数据可得性与时效性。
💼 BD 关联：中国卫星数据被明确纳入印尼国家级生态监测，是明华切入蓝色碳汇监测产品与高分/HY 数据增值服务的窗口；可对标其"多源融合 + 可解释警报"方法，向 BNPB/KLHK 输出可复核产品。
