▎卫星通信

Starlink 拟在马来西亚试验直连手机（D2C），从固定宽带走向移动连接🔴 高

来源：Light Reading / Communications Today / SatellitePro ME · 日期：2026-07-29（Fahmi 表态）
  • 通信部长 Fahmi Fadzil 7/29 表示，Starlink 代表已提出在马试验 Direct-to-Cell（D2C）技术，MCMC 被要求召集本地移动运营商对接探讨部署。
  • D2C 让标准 4G LTE 手机直连 LEO 卫星，无需专用终端，覆盖无塔偏远村、高速路、离岸场景，主打短信 / 语音 / 应急通信；马来西亚拟用 900/1800MHz 低频段。
  • 区域首例为菲律宾 Globe（2026.6 商用，东南亚首个 Starlink D2C 服务）；Ookla 报告显示 APAC D2C 用户 2025.7–2026.5 增长逾 5 倍，菲律宾占区域多数。
💼 BD 关联：D2C 试验窗口开启，合规 B2B 海事 / 离岸 / 应急直连手机终端与运营方案需求显现。Astrolink 可定位持证、可追溯的合规终端方案，回应灰色安装监管缺口；同时评估与 MEASAT（Starlink 授权经销商）在二级集成上的协同。

MEASAT 多轨道转型：GEO＋Starlink LEO 集成，主推托管服务与垂直 SaaS🟡 中

来源：The Edge Malaysia（Digital Edge 封面）· 日期：2026-07-13～19
  • 新任 CTO John Loke（2026.4 回归）获命推动公司从「卖带宽」转向托管服务、软件与垂直应用，目标成为医院 / 政府 / 农渔社区真正依赖的「成效」伙伴。
  • 采用多轨道集成：以 SD-WAN 将 Starlink LEO 低时延与自有 GEO 高可靠备份融合，提供混合连接；并自建远程医疗、农业传感器、海事连接等垂直 SaaS。
  • 作为 Starlink 授权经销商，借 Malaysia Madani 数字包容政策与 rural broadband 关系，向政府 / 油气 / 农村场景下沉。
💼 BD 关联：MEASAT 由「容量销售」转向「平台 + 应用」意味着其对地面段、行业应用、增值数据有新增采购与合作需求。Astrolink 可评估在其多轨道托管方案中的地面段 / 行业应用配套角色。

MEASAT × SpaceSail（千帆）MoU：为马来西亚保留中国 LEO 战略选项🟡 中

来源：Via Satellite / SpaceNews / MEASAT / 金融界 / 通信世界网 · 日期：2025-02-06 签，持续有效
  • 2025.2.6 上海签非约束性 MoU：MEASAT 作批发分销 / 多轨道集成商，引入千帆 LEO 宽带、D2D、卫星 IoT 与 EO；并联合开展 Q/V 频段雨衰研究。
  • 千帆在轨提速：截至 2026.4 已达 126 颗、2026.6 增至 200+ 颗，目标 2026 年内初步全球覆盖、年底试商用（待卫星互联网牌照）；MEASAT 借此零星座资本开支获得多轨道能力。
  • 商业服务落地取决于千帆成熟度（约 3–5 年），当前为「战略选项」而非在运服务；属公司级协议，非部长级签约。
💼 BD 关联：千帆出海马来西亚的节奏由 MEASAT 背书驱动。明华 / Astrolink 可跟踪该 MoU 兑现节点，评估在千帆马来西亚落地中的地面段、数据接收或增值服务配套机会（与中国商业航天出海主线协同）。

  • 工作坊汇聚部委 / 学术机构与国际 SBAS / GNSS 专家，评估马现有 SBAS 技术能力、识别差距、分享最佳实践、制定 SBAS 实施战略。

MyRTKnet 109 站 CORS 多星座覆盖，北斗仍处合作计划层面⚪ 低

来源：MYSA / JUPEM 论文 / Belt and Road Initiative 合作清单（背景性，非本期新发）
  • 马来西亚 MyRTKnet（JUPEM 运营）已扩展至 109 个 CORS（Phase V），多数支持 GPS＋GLONASS＋Galileo，部分含 BeiDou，作为国家大地基准。
  • 北斗在马被列入中国「太空丝绸之路」合作计划（含 BDS ASEAN 数据中心），但本期检索未见新的马来西亚—北斗官方合作公开动态；邻国柬埔寨已落地北斗数据分中心，马仍处计划层面。
💼 BD 关联：存量 CORS 已含北斗、设备层兼容，但官方合作未启动。明华可走农机、工程机械、海事终端等增量层绕开存量壁垒，并跟进 MYSA SBAS 规划中的北斗增强机会。

▎遥感

Eartheye Space × SAINS 砂拉越 EO / SAR 合作，建云端卫星数据平台🟡 中

来源：Eartheye Space（官方发布）· 日期：2026-01-27（APACE 2026 启动仪式，砂总理见证）
  • Eartheye Space（新加坡）与砂拉越政府信息系统公司 SAINS（州政府全资）签 MoU，聚焦 SAR、光学、高光谱数据的处理与分析。
  • 合作建安全云端卫星数据平台，实现任务规划 / 处理 / 分析一体化，支撑基础设施、环境、灾害、城市规划、资源管理试点项目。
  • 对齐砂拉越 PCDS 2030（后疫情发展策略），并设培训 / 联合 workshop / AI-ML 模型共建等能力建设内容。
💼 BD 关联：砂拉越为马遥感需求高地（雨林 / 海岸 / 灾害）。明华 / Astrolink 可对标 Eartheye，推 SAR / 光学数据分销或灾害 / 资源管理联合应用，争取州级示范项目。

国家遥感卫星 PSPJN 推至 2028 初，AIT（万津）能力建设待释放⚪ 低

来源：NST / Bernama / 南洋商报（较早，作停滞背景）
  • 国家遥感卫星发展计划（PSPJN）首批 RFP 因投标方未达强制技术要求，内阁 2024.1.31 同意重开招标，运营推至 2028 初。
  • 目标为数据主权与降本（不再外购遥感数据），由 MYSA 监督、PPP 模式；雪州万津已设卫星组装集成测试中心（AIT）。
  • 本期无该计划新增公开进展，进度仍处于招标 / 能力建设阶段。
💼 BD 关联：PSPJN 为中长期数据主权机会，PPP 招标与 AIT 能力建设窗口明确。Astrolink 可提前卡位地面段 / 数据接收 / 子组件配套，待 2028 前后招标启动。

▎发射与卫星

砂拉越航天港 + 新空间（厦门）航天 × 御蓝天航天战略合作落地🟡 中

来源：泰伯网 / 新空间航天集团 · 日期：2026-06-28 签（7/5 披露）
  • 新空间（厦门）航天与马来西亚御蓝天航天签战略合作协议，覆盖发射场建设、运载发射服务、技术协同、地面测控设施共享。
  • 未来三年共建发射支持中心与联合测试设施，探索中马联合卫星星座、航天研学与人才培养；首个商业火箭发射计划 2026 在砂拉越启动。
  • 合作借砂拉越近赤道地理优势，为中方火箭提供低纬度发射机会，亦助马方航天港快速具备国际商业发射能力。
💼 BD 关联：中国商业航天「出海」主线在马落地明确。明华 / Astrolink 可借该合作对接砂拉越航天港 / 御蓝天，争取地面段、测运控、数据接收或联合星座配套（与中国企业协同，规避单打独斗）。

MEASAT-3d 在轨运营 + MYSA 发射场可行性研究（生态背景）⚪ 低

来源：MEASAT / MYSA（背景性，无本期新增）
  • MEASAT-3d（2022 发射，GEO HTS，覆盖马来 / 印尼 / 印度）持续运营，支撑 JENDELA 数字连接计划。
  • MYSA 自 2024 起探索火箭发射场可行性并拟建指南；马本土尚无自主发射能力，卫星多依赖外部（法属圭亚那、日本 H3、ISS 部署）。
💼 BD 关联：发射场从可行性走向建设期，地面段 / 测运控基建需求将随砂拉越航天港推进释放，Astrolink 可提前布局配套能力。
