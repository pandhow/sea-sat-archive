▎卫星通信

Starlink 越南试点正式获牌并推进部署

来源：Vietnam News / VOV / 人民军队报（越通社） · 日期：2026-04-01（获牌）；试点机制自 2026-02 起 · 热度：🟡 中

  • 越南电信管理局（VNTA）于 2026-02-14 向 Starlink Services Vietnam 颁发频率与设备使用许可，2026-04-01 正式发牌（固定 + 移动卫星网络服务），5 年试点，须于 2031-01-01 前结束。
  • 初期部署 4 个网关站（Phú Thọ 富寿、Đà Nẵng 岘港、HCM 胡志明），终端上限 60 万台，用户规模严格受控。
  • 定价高端：首月约 $435（设备 $350 + 订阅 $85），次月起约 $85/月，首年约 $1,370（约 3,400–3,500 万越南盾），为光纤资费 5–10 倍 → 奢侈品 / 补充覆盖定位。
  • 进度：设备进口与安装顺利则 mid-2026 启用；越南固网已较完善，Starlink 定位偏远地区、海岛及海底光缆故障时的备用连接。
💼 BD 关联：Starlink 试点 4 个网关站正值建设期，地面段配套、网络安全合规、备用链路方案是明华 / Astrolink 可对标泰国 Thaicom 4 退服窗口的经验输出方向；一线 BD 须核实越南是否对第三方地面段 / 网关配套开放采购。

VINASAT-3 实施 + VINASAT-4 规划（主权 GEO 延续）

来源：Mondaq / 越南科技部（MST）· 日期：2026（规划确认）；Thales 会谈 2026-04-02 · 热度：🟡 中

  • 越南科技部确认正在实施 VINASAT-3，并规划 VINASAT-4 替换 VINASAT-2（约 2030 寿命终止）；VNPT 被指定为主实施单位。
  • VINASAT-1（2008，洛马造、阿里安发射）约 2023 到设计寿命；VINASAT-2 于 2012 发射，主权通信卫星体系由越南国有 VNPT 运营。
  • 2026-04-02 越南科技部副部长 Pham Duc Long 会见 Thales Group，讨论电信卫星（Ku/Ka 多波段、星上数字处理器）、网络安全与技术转移；Thales 已与 VNPT 接洽，准备提供电信卫星解决方案（含印尼 Satria-1 经验）→ Thales 为 Vinasat-3/4 潜在主供应商。
💼 BD 关联：VINASAT-4 换代窗口（2030 前）是越南 GEO 卫星地面段 / 关口站设备与运维的潜在机会；但 Thales 系主供应商、竞争激烈，明华 / Astrolink 宜从地面段配套、网络安全合规、培训等非核心环节切入，并紧盯 Vinasat-4 招标节奏。

🆕 Vingroup / VinSpace 入局商业航天

来源：The Investor / VnExpress / DTiNews · 日期：2026-04（披露于 Vingroup 2025 年报）· 热度：🟡 中（🆕 新信号）

  • VinSpace 由亿万富翁 Pham Nhat Vuong 于 2025-11-03 成立（注册资本 VND 3,000 亿 ≈ $11.4M），Vuong 持股 71%、Vingroup 19%。
  • 目标 2027 年首发微卫星（"Make in Vietnam" 纳卫星集群），提供通信 + 遥感商业服务，是越南首个私企航天玩家。
  • 正在建设洁净室、测试设备与地面站系统；寻求国内外伙伴技术转移，构建航空航天生态。
  • 越南此前仅国家航天中心（VNSC）造过微卫星（2013 PicoDragon、2021 NanoDragon）。
💼 BD 关联：越南商业航天破冰，长期跟踪 VinSpace 洁净室 / 地面站 / 遥感商业化需求；明华 / Astrolink 可在地面段设备、遥感数据应用、人才培训方向提前建立联系（短期无订单，属卡位）。

▎导航（GNSS / 北斗）

VNGEONET 65 站 CORS（设备层已兼容北斗）

来源：Leica Geosystems 案例 / VNGEONET 官网 / Vietnam.vn · 日期：存量（2019 完工）+ 2026 应用 · 热度：⚪ 低

  • VNGEONET 由越南测绘地信局（DOSMVN）建设，2016 启动、2019 完工，65 站 CORS（24 大地测量级 + 41 NRTK），Leica GR50（555 通道）支持 GPS / GLONASS / Galileo / BeiDou 全星座 → 设备层早已兼容北斗。
  • 2026-01~03 河内杜嘉恩综合医院无人机医疗运输试点，用 VNGEONET 实时 GNSS 校正（厘米级）+ MobiFone 5G，保障城市无人机走廊安全飞行。
  • 越南导航坐标系为 VN-2000（WGS84 + 7 参数 Helmert 变换），监管严格，地籍 / 土地登记须转回本地坐标。
💼 BD 关联：越南导航无新增北斗合作公开信号，但设备层已兼容北斗；明华 / Astrolink 可从终端增量层（农机、工程机械 RTK 终端、北斗增强应用）绕开存量壁垒切入，并通过一线 BD 核实越南是否放开北斗增强服务市场准入。

Thales MEOLUT Next / COSPAS-SARSAT 搜救（基于 Galileo）

来源：Thales 越南 · 日期：2026（合作背景）；Yagi 台风 2024-09 验证 · 热度：⚪ 低

  • Thales Alenia Space 与 VIETTEL 合作为 VINAMARINE 提供 MEOLUT Next 站，接入 COSPAS-SARSAT 全球搜救网（基于 Galileo 定位）。
  • 2024-09 超强台风 Yagi 过境期间，系统成功接收并记录两船遇险信号（风速超 150 km/h），救起 20 名船员，验证极端天气可靠性。
💼 BD 关联：越南搜救 / 海事导航基础设施由 Thales + VIETTEL 主导，明华短期难切入；作为导航板块现状背景记录，持续观察。

▎遥感

🔴 JAXA × VNSC 修订卫星数据交换协议（7/30）

来源：Japan Earth Observer（JEO 18 News Roundup）· 日期：2026-07-30 · 热度：🔴 高

  • JAXA 与越南国家航天中心（VNSC）签署修订版卫星数据交换协议；原协议 2017-09，聚焦 ALOS-2 数据用于灾害管理 / 农业 / 林业。
  • 新协议扩展至 ALOS-4（DAICHI-4），并加强 APRSAF「Space Applications for Environment (SAFE)」框架下的联合研发。
  • JAXA 同时通过日本 ODA 资助支撑 LOTUSat-1 发射，日越遥感合作形成"数据 + 卫星 + 研发"完整链条。
💼 BD 关联：日越遥感合作升级直接强化越南遥感数据获取与处理能力，明华 / Astrolink 遥感业务可探索：ALOS-4 数据本地化应用合作、VNSC 数据地面处理 / 培训、灾害与农业遥感应用联动；建议朱然 / 遥感团队跟进东盟遥感数据生态。

VNSC 国家航天中心揭牌运营（存量重要基础设施）

来源：VnExpress / VN Economy / 岘港报 · 日期：2026-03-13 · 热度：🟡 中

  • 越南国家航天中心（VNSC）2026-03-13 在河内和乐高科技园区正式揭牌，日 ODA 贷款，投资超 VND 7 万亿（约 $266M），占地 9 公顷。
  • 含运控中心、卫星数据利用与应用中心、卫星研发设施、9.3 米天线地面系统、航天博物馆。
  • 总理范明政称其标志越南从"建基础"转向"运营应用、逐步掌握空间技术"的新阶段；目标 2030 年成为东盟中上水平航天国家。
💼 BD 关联：VNSC 是越南遥感 / 卫星数据核心基础设施，属长期客户关系锚点；明华 / Astrolink 宜将其列为越南遥感 BD 重点对接机构。

LOTUSat-1（X-band SAR）制造完成待发射

来源：WMO OSCAR / Tuoi Tre / Envisioing · 日期：2026（状态更新）；spacelive 发射状态"待确定" · 热度：🟡 中

  • LOTUSat-1 由 NEC 基于 ASNARO-2 / NEXTAR NX-300L 平台制造，600kg X-band SAR，分辨率 1m（Spotlight）/ 2m（Stripmap）/ 16m（ScanSAR），全天候昼夜成像。
  • 制造已完成，待发射；总理督办 2027 年底前发射；由 JAXA Epsilon S 从内之浦航天中心发射。
  • 受阻：Epsilon S 试飞失败（2024）导致无确定档期，发射状态仍"待确定"。
💼 BD 关联：LOTUSat-1 是越南首个 SAR 能力，明华遥感团队可提前研究其数据产品与应用场景，待其入役后探索数据代理 / 应用合作；发射依赖日本，短期无本土发射合作空间。

▎发射与卫星

VinSpace 地面站 / 洁净室建设（2027 首发目标）

来源：The Investor / VnExpress · 日期：2026-04 · 热度：🟡 中

  • VinSpace 正在建设洁净室、测试设备与地面站系统，确保 2027 年首发微卫星进度。
  • 越南无自主发射设施 → 须依赖国际伙伴发射；短期以实验性小规模首发为主，商业化取决于市场需求与人才供给。
💼 BD 关联：越南发射能力空白，VinSpace 2027 首发必寻国际发射伙伴；明华火箭业务（主力方向之一）可作为未来东南亚发射服务候选供应商提前跟踪，但越南当前绑日本 ODA、短期难切入，属长期卡位。

VINASAT-3/4 卫星动态（VNPT 主责，发射档期未定）

来源：Mondaq / 越南科技部（MST）· 日期：2026 · 热度：🟡 中

  • VINASAT-3 实施中、VINASAT-4 规划中（替换 VINASAT-2，约 2030 寿命终止），VNPT 主实施；发射服务商 / 档期未公开。
  • 频段由 C 向 Ku/Ka 演进（Thales 观点），与区域 GEO 换代趋势一致。
💼 BD 关联：GEO 卫星换代带来地面段 / 关口站更新需求，明华 / Astrolink 可关注 VNPT 招标与 Thales 分包机会。

越南本土发射 / 地面站重大动态（如实标注）

  • 越南无自主发射能力、无可靠公开的新增发射 / 地面站重大动态；LOTUSat-1 发射档期仍"待确定"（受 Epsilon S 拖累）。

🧭 与明华 / Astrolink BD 的业务衔接建议

  1. [P0] 越南导航增量市场——VNGEONET 设备层已兼容北斗，明华 / Astrolink 从农机、工程机械 RTK 终端、北斗增强应用切入，绕开存量壁垒；一线 BD 核实越南是否放开北斗增强服务市场准入。
  2. [P1] 遥感——JAXA × VNSC 7/30 协议升级 + VNSC 运营 + LOTUSat-1 待发射，明华遥感业务对接 VNSC / 数据应用 / 培训（朱然 / 遥感团队跟进东盟遥感数据生态）。
  3. [P1] GEO 换代——VINASAT-3/4（VNPT）+ Thales 合作，关注地面段 / 关口站招标与分包机会，避开主供应商正面竞争。
  4. [P2] Starlink 试点 4 网关站建设——地面段配套 / 网安合规 / 备用链路方案对标泰国 Thaicom 4 退服窗口经验。
  5. [P2] VinSpace 商业航天——越南首个私企航天玩家，长期卡位地面段 / 遥感商业化 / 培训，短期无订单。
