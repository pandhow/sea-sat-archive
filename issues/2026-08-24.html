▎卫星通信

Starlink 越南商用正式上线，60 万用户上限、四网关站落地

来源：Entrepreneur APAC / Vietnam.vn / 动点科技（8/13）/ VietnamNet ｜ 日期：2026-08-13

🔴 高

  • SpaceX 全资子公司 Starlink Services Vietnam 于 8/13 正式开放商业接单，住宅 $43/$66(标准) 月、企业起价 $57，硬件约 $329–440。
  • 已建 4 座境内网关站（富寿 / 岘港 / 胡志明市），试点上限 60 万终端，期限至 2031-01-01；越南系其第 6 个东南亚市场。
  • 越捷航空（Vietjet）已签机上网络连接协议；多家分析指出其主战场在海上、偏远、备份通信，对城市光纤不构成价格竞争（价格约为 VNPT 光纤 5 倍以上）。
💼 BD 关联（Astrolink / 明华）：Starlink 入越后，"地面补盲 + 合规网关周边"成明确切口——明华可推海上/偏远 VSAT 备份、渔政/海警互联、跨境企业专网备份方案，与 Starlink 形成互补而非正面竞争；同时关注其网关站周边合规集成与运维窗口。

VINASAT-3/4 国家通信卫星换代加速，Thales 推进与 VNPT 合作

来源：VietnamNet / Mondaq（Duane Morris）｜ 日期：2026-06~2026-08（持续进行）

🔴 高

  • 越南科技部确认推进 VINASAT-3 项目，并规划 VINASAT-4 作为 VINASAT-2（设计寿命约 2030 到期）的替代星，定位"数字主权 + 基础设施韧性"。
  • 法国 Thales 于 6/11 随总理访法时正式提议参与 VINASAT-3（与国有 VNPT 合作），总理要求科技部与 VNPT 透明公平竞标。
  • VINASAT-1（2008 发射、Lockheed Martin 造、Ariane-5 发射、设计寿命 2023 止）可靠性下降，替代规划紧迫。
💼 BD 关联（Astrolink / 明华）：国家级通信星换代是中长期大单窗口——可切入地面段、频段协调、测控与增值通信服务咨询；同时以"中国航天 GEO 通信星 + 地面应用"差异化方案参与关系卡位，不与 Thales 正面争夺主星制造。

▎导航（GNSS / 北斗）

Circular 12/2026 农机北斗强制认证 10/1 生效倒计时

来源：越南工贸部 MOIT / zsiron / The Indus Wire｜ 日期：2026-04~2026-08（10/1 生效）

🔴 高

  • MOIT Circular 12/2026/TT-BCT 要求进口拖拉机、插秧机、谷物烘干机等农机的 GNSS 模块须为 BeiDou-3 双模 并取得 VINA-STAR 认证，自 2026-10-01 起海关强制核验，未合规即拒入。
  • 配套要求 GNSS 定位精度校准报告须由 CNAS（ISO/IEC 17025）认可实验室出具，认证周期 6–8 周；华南/山东约 70% 越南农机来源地承压。
  • 政策信号：越南将 GNSS 兼容从"性能要求"转为"架构前置"，反映东盟农业 GNSS 主权化趋势。
💼 BD 关联（Astrolink / 明华）· P0：这是本期最高优先级切入点——明华可牵头北斗模块供应 + VINA-STAR 认证代理 + CNAS 预校准一站式服务，绑定华南/山东出口链；建议在 10/1 前完成首批合规样机与认证通道，抢占窗口期。

北斗 PPP 完成在轨升级，越南交通部拟集成北斗车辆追踪

来源：中国卫星导航系统管理办公室 CSNO（7/31）/ 越南交通部动向｜ 日期：2026-07~2026-08

🟡 中

  • 北斗完成全面在轨升级（7/31 公布），PPP 水平精度 <0.3m、双星座 59 颗修正卫星，亚太地区直接受益。
  • 越南交通部层面出现将北斗集成进车辆追踪/物流监管的意向，与农机北斗认证形成"陆上+田间"双线推进。
💼 BD 关联（Astrolink / 明华）：借北斗 PPP 升级红利，推车辆追踪/物流/车队管理北斗终端，与农机认证形成"北斗应用套件"；可作为农机 P0 项目的自然延伸。

农业环境部鼓励卫星定位站进入高科技农业

来源：越南农业与环境部（mae.gov.vn）｜ 日期：2026-03-17

⚪ 低

  • 副部长主持会议，鼓励卫星定位站在精准种植、自动喷药施肥等高科技农业应用，配套推进国家定位网络扩展与 3D 地图标准。
  • 属政策背景信号，近期无新增重大落地动作。
💼 BD 关联（Astrolink / 明华）：长期关系卡位方向——与农业部/测绘地信部门保持技术交流，为北斗+遥感农业应用储备政府侧触点。

▎遥感

VNSC 越南国家航天中心运营，LOTUSat-1 SAR 目标 2027 年底发射

来源：越南政府网 chinhphu.vn / Tuoi Tre / VOV｜ 日期：2026-03-13 启用，2027 待发

🔴 高

  • 越南国家航天中心（VNSC，Hoa Lac 高科技园，日 ODA 贷款逾 7 万亿越盾/约 2.66 亿美元）3/13 盛大启用，含运控中心、卫星数据应用中心、9.3m 天线地面系统、洁净间。
  • LOTUSat-1（首颗 SAR 雷达星，约 600kg，日越联合制造）已完成制造、地面系统已安装，总理呼吁日越协调保障 2027 年底 发射；具 1m 分辨率、昼夜全天候能力。
  • MicroDragon-2（约 50kg 实验星）在研，用于森林监测与国产设计验证。
💼 BD 关联（Astrolink / 明华）：日越绑定项目，明华宜寻 NEC/住友等日本主承包商二级合作，切入地面站周边设备与遥感应用；同时以自研遥感方案对接 VNSC 数据应用中心，提供农业/海洋/应急 downstream 能力。

⚠️ 事实核查：LOTUSat-1 目前 仅完成制造、尚未发射，官方与多源一致口径为"目标 2027 年底"。部分中文科技媒体曾误报"已成功发射"，本期拒绝该误报，延续第 027 期已报结论，严禁写成已入轨。

卫星列入国家 11 项战略技术，航天法立法推进

来源：越通社 VietnamPlus｜ 日期：2025-06 ~ 2026 持续

🟡 中

  • 1131/QĐ-TTg（2025-06-12）将航空航天技术列入 11 项战略技术；第 57 号决议强调航天研究应用，第 193 号决议提供法律走廊。
  • 《越南航天法》立法方向明确，目标 2030 建成东南亚中上游空间能力；VNSC 承担核心技术转移与数据生态构建。
💼 BD 关联（Astrolink / 明华）：立法窗口期是关系卡位良机，可借明华/海南卫星数据与应用研究中心能力，提前与 VAST/VNSC 建立技术与数据合作通道。

▎发射与卫星

VinSpace（Vingroup）× SpaceX 签正式发射合同，2027 发越南首颗私营星座

来源：SatNews / SmallSatNews / Business Wire（8/18）｜ 日期：2026-08-15 签约

🔴 高

  • VinSpace（Vingroup 航天子公司，2025-11 成立）8/15 与 SpaceX 签发射服务合同，2027 搭 Transporter 拼车任务发射首批商业纳米卫星（"Make in Vietnam"）。
  • 载荷含高分辨率光学遥感 + 窄带物联网/IoT 通信，用于农业监测、海岸带管理、基础设施与海事 M2M；采用太阳同步轨道。
  • 标志越南从国家院所项目转向私营商业航天，VinSpace 目标成为全栈（设计—AIT—发射管理—运营—下游数据）航天公司。
💼 BD 关联（Astrolink / 明华）：越南首个私营星座具"早卡位"价值——可在 AIT、地面测控站、下游数据分发（农业/海事/应急）切入合作；明华遥感方案与 VinSpace 光学载荷形成应用层互补，建议尽快建立技术对接。

越南无自主发射能力，入轨全靠外部运载

来源：综合本期各源｜ 日期：2026-08-24 评估

⚪ 低

  • LOTUSat-1 将借日本运载 2027 发射；VinSpace 借 SpaceX Transporter；越南本国无发射场/运载火箭。
  • 本期无新增自主发射或发射场建设公开动态，如实标注低热度，未编造。
💼 BD 关联（Astrolink / 明华）：越南的"无发射能力"恰是明华/中国火箭出口与发射服务的潜在入口——可关注未来越南政府对发射服务的采购意向，但当前以数据与应用层合作为更务实切入点。

🧭 与明华 / Astrolink BD 的业务衔接建议

  • P0农机北斗强制认证 10/1 倒计时：明华牵头 BeiDou-3 双模模块供应 + VINA-STAR 认证代理 + CNAS 预校准一站式服务，绑定华南/山东出口链，抢在生效前完成首批合规通道。
  • P0VinSpace×SpaceX 2027 早卡位：对接越南首个私营星座的 AIT、地面测控与下游数据分发（农业/海事/应急），以明华遥感方案形成应用层互补。
  • P1Starlink 商用互补：海上/偏远/备份 VSAT、渔政海警互联、企业专网备份，与 Starlink 错位竞争；关注网关站周边合规集成。
  • P1VINASAT-3/4 国家换代：以中国 GEO 通信星 + 地面应用差异化切入 Thales×VNPT 主星之外的地面段/频段咨询窗口。
  • P1LOTUSat-1 SAR + Hoa Lac 地面站：日越绑定项目寻 NEC/住友二级合作，配套遥感应用对接 VNSC 数据应用中心。
  • P2北斗 PPP 升级 / 车辆追踪终端：借 PPP <0.3m 红利推物流车队北斗终端，延伸农机套件。
  • P2《越南航天法》立法关系卡位：借第 57/193 号决议窗口与 VAST/VNSC 建长期技术—数据合作通道。
