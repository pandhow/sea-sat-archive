▎卫星通信

千帆 / G60星链（上海垣信）首相级会晤，推动低轨卫星互联网入场

🔴 高
来源：柬中时报 / cambolist / 搜狐　|　日期：2026-07-17
  • 7/17 洪玛奈首相在出席 WAIC2026 期间于上海会见上海垣信卫星科技董事长郑杰（Jason Jie Zheng）。
  • 双方探讨将「千帆星座」（G60星链）低轨宽带卫星互联网及卫星直连手机（Direct-to-Cell）技术引入柬埔寨。
  • 上海垣信明确有意在柬投资并提供卫星互联网 / 卫星通信服务；洪玛奈欢迎该意向。
  • 首相强调 MPTC 正在制定卫星互联网与通信服务法律框架；待法规落地后优先覆盖偏远农村、并防止服务滥用。
💼 BD 关联：千帆入场将是柬埔寨首个合规 LEO 卫星互联网玩家，窗口期在「法律框架出台前」。明华 / Astrolink 建议优先建立与 MPTC（邮电部）及上海垣信的双向情报接口，定位为地面段 / 关口站 / 行业应用集成伙伴，而非频谱竞争者。重大合作须以官方与一线 BD 核实。

Starlink 在柬仍属未批准状态，监管真空催生合规玩家差异化机会

🟡 中
来源：TRC / 高棉时报 / cambolist　|　日期：2025-09 禁令持续；2026-05-25 执法记录
  • 柬埔寨电信监管局（TRC）从未批准 Starlink 在柬运营（无型号核准证书、SpaceX 未在柬设业务），进口 / 分销 / 使用均属违法。
  • 黑市交易猖獗，非法设备常被电诈团伙用于规避网络监管；2026-05-25 国公省别墅反诈突袭查获非法 Starlink 接收器。
  • 第三方测速显示若合法化，Starlink 在柬约 132Mbps 下行 / $61 月费，但相对收入负担重（首年约 $1,414，≈当地中位年收入 33.7%）。
💼 BD 关联：监管真空 + 反电诈执法刚需，为合规 LEO（千帆）与本地安全合规方案创造差异化切入点；明华可关注「合规卫星互联网 + 反诈 / 边境监管」叙事，绕开 Starlink 灰产竞争。

▎导航（GNSS / 北斗）

全国 CORS 卫星基准站网络推进：截至 7/7 已完成 72 桩、52 站通电

🟡 中
来源：MLMUPC / cambolist　|　日期：2026-07-07（5/31 已完成 66 桩 / 37 通电）
  • 土地管理与城市规划建设部（MLMUPC）主导，截至 7/7 完成 72 个基准站混凝土桩，52 站已完成电力 + 防雷系统 + 主控制柜安装。
  • 目标：提升土地登记精度、支撑智慧城市规划与科研。
  • 项目建设节奏稳定，从 5/31 的 66 桩 / 37 通电推进至 7/7 的 72 桩 / 52 通电。
💼 BD 关联：CORS 进入设备安装尾声，下一阶段是运营与终端应用层（接收机、RTK 终端、行业软件）。明华 / Astrolink 可对接具备 GNSS 装备供应与运维能力的伙伴（参考北斗国星 / 中海达体系），定位「设备 + 运维 + 培训」打包。

JICA 赠款签约：共建 94 站 CORS + 数据中心（约 $9.7M）

🟡 中
来源：JICA / CPP　|　日期：2026（近期签署）
  • 柬埔寨经济财政部（MoEF）与 JICA 签署赠款协议，价值 JPY 1,338M（约 $9.7M）。
  • 通过无偿资金援助，全国共建 94 个 CORS 站 + 数据中心，接收 GNSS 高精度定位数据并分发。
  • 配套自 2021 年起技术合作项目（5 套 CORS + 数据中心试点、运维提升、推广应用）。
💼 BD 关联：日方主导 funding，但设备采购 / 集成 / 本地化服务存在供应链机会；关注 JICA 招标与 MLMUPC 采购节奏，明华可携北斗兼容 GNSS 装备切入。

北斗落地加速：国家北斗导航位置服务数据分中心 + 中海达 UNDP 减灾项目

🟡 中
来源：北斗国星 / 中证网（中海达）　|　日期：2026（近期）
  • 北斗国星与柬埔寨签署「国家北斗导航位置服务数据分中心」落户合作协议，明确先在交通运输领域试点，着手北斗终端及应用系统平台研发。
  • 中海达（北斗高精度定位首家上市企业）借 UNDP「科技助力减灾一带一路」项目落地柬埔寨，提供人才培训、技术转移，已在「一带一路」共建 100+ 北斗地基增强站。
  • 公开盘点：泰国、柬埔寨、缅甸、马来西亚等亚洲多国已全域落地北斗。
💼 BD 关联：北斗在柬已有「国星数据分中心 + 中海达减灾」双线落地，明华 / Astrolink 的北斗业务（朱然对接）应避免与存量玩家正面竞争，建议走交通 / 农业 / 边境差异化行业应用，或做终端与系统集成。

▎遥感

邮电部 4/23 研讨会设定「5 年内自主发射卫星」愿景，聚焦农业 / 环境 / 城市规划

🟡 中
来源：AKP / 柬中时报 / asianspeech　|　日期：2026-04-23
  • 邮电部长谢万迪（Chea Vandeth）在「卫星监测与数据采集技术」研讨会闭幕式上表示，柬埔寨考虑未来 5 年内自主发射卫星，服务农业、环境监测、土地管理与城市规划。
  • 同步研究设立国家航天管理机构（National Space Management Unit）统筹外空事务。
  • 研讨会由 Pixxel Space Technologies（高光谱遥感小卫星公司）CEO Awais Ahmed 主讲，内容含 EO 系统、遥感卫星、高光谱影像分析。
  • 官方盘点：柬埔寨与文莱、缅甸、东帝汶同为东盟「尚未发射自主卫星」的经济体。
💼 BD 关联：遥感需求明确（农业 / 环境 / 国土），但本国无在轨资产，短期仍依赖商业 EO 数据采购与服务。明华 / Astrolink 可推「遥感数据 + 行业解译」轻量方案（无需自建卫星），契合其地面段 / 应用短板；高光谱（Pixxel）是可跟踪合作方。

▎发射与卫星

尚无自主卫星 / 发射 / 运营星座动态；机构与人才建设为唯一实质信号

⚪ 低
来源：MPTC / JAXA Kibo-ABC　|　日期：2019 Satellite Policy Dept；2025-11 加入 Kibo-ABC；2026-03 Space Policy 研讨会
  • 柬埔寨目前无任何在轨自主卫星，也无公开的商用发射 / 地面站运营动态。
  • 实质性进展集中在体制机制：MPTC 2019 设 Satellite Policy Department，正重组为 Satellite and Space Department；2025-11 加入 JAXA Kibo-ABC（含 Kibo Robot Programming Challenge 等航天教育）。
  • 自主发射仍处「研究 / 愿景」（Vision 2031）阶段，区域专家指关键瓶颈为「地面段（数据处理中心 + AI 分析）」而非发射本身。
💼 BD 关联：发射与卫星板块本期无新增公开动态（低热度）——柬埔寨短期不会成为发射市场，但「地面段 + 数据处理 + AI 分析」是真实缺口。明华 / Astrolink 应以「应用与地面段赋能」而非「发射服务」定位切入，避免臆测发射订单。

⚠️ 旧闻甄别与提示：本期无 2023 年 PSLV-C56/DS-SAR、MEASAT×上海垣信（2025-02）等回流旧闻干扰。Starlink 在柬「黑市 / 禁令」为持续背景事项，非本期新增；千帆（上海垣信）7/17 会晤为本期最高 BD 价值新信号，重大合作须以官方与一线 BD 核实。越南「发射与卫星」板块如有类似空白亦按低热度如实标注。
