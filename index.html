关于本归档

这是一个纯前端的 SPA（单页应用）历史归档站，用于归档「东南亚卫星产业动态」每日自动生成的 HTML 报告（监测泰国、印度尼西亚、马来西亚、新加坡、柬埔寨、越南在卫星通信 / 导航（GNSS·北斗）/ 遥感 / 发射与卫星 四大领域的动态）。

发布节奏（一国一日轮值）：周一至周六每天聚焦一国——越南（一）/ 柬埔寨（二）/ 泰国（三）/ 马来西亚（四）/ 印尼（五）/ 新加坡（六），分别覆盖四大领域，减少每日资讯重叠；周日发布「本周高热度回顾」，汇总当周最热资讯与六国 × 四领域活跃度矩阵。

架构

  • 外壳 index.html + app.js + styles.css：列表/路由/渲染
  • 数据 data/manifest.json：期次清单（日期/标题/标签/文件路径）
  • 内容 issues/YYYY-MM-DD.html：每期报告独立 HTML，iframe 载入

新增一期

  1. 把报告 HTML 丢进 issues/（命名 YYYY-MM-DD.html）
  2. 在 data/manifest.json 的 issues 数组顶部加一条
  3. 刷新页面即可

本地运行

cd sea-sat-archive
python -m http.server 8080
# 浏览器打开 http://localhost:8080

直接双击 index.html 也能看（但 fetch manifest 需要 http 协议，建议用上面的本地服务器）。
